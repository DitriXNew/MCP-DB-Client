# Поиск шагов, примеров и правил Vanessa Automation (RAG)

Этот MCP-сервер — Vanessa Automation (BDD-тестирование 1С) с семантическим поиском.

## Коллекции (актуальный список — инструмент list_collections)
- vanessa_steps — все шаги Ванессы. Текст хита = готовый текст шага; meta.type = категория, meta.lang = язык.
- vanessa_kb — база знаний: вопросы-ответы «как правильно писать сценарии» с Gherkin-примерами; meta.num = номер вопроса.
- прочие — файловые коллекции проекта (например, фича-файлы): doc_id = путь к файлу, line_start/line_end = строки файла.

## Как подобрать шаг
1. Сформулируй действие по-русски своими словами и вызови search:
   {"query":"нажать на кнопку формы","collection":"vanessa_steps","mode":"dense","k":10}
   - dense — поиск по смыслу (падежи, синонимы, языки не мешают); хорошие скоры 0.75–0.92.
   - hybrid/keyword — для точных подстрок и идентификаторов; скоры hybrid — это RRF (~0.03), min_score не задавай.
2. Бери ТОЧНЫЙ текст шага из поля text хита; значения параметров подставляй в той же форме кавычек ("..." или '...').
3. Описание, сниппет и параметры шага: инструмент search_for_steps_by_keywords с search_name = точный текст шага.
4. Фильтр по категории: "filter":{"all":{"type":"UI.Формы.Кнопки"}} (категория видна в meta.type хита).

## Примеры использования шагов в реальных сценариях
- grep: {"pattern":"нажимаю на кнопку","collection":"<файловая>","ignore_case":true,"context_lines":2} — найдёт строки фича-файлов.
- get_segment: {"doc_id":"<путь из хита>","line_start":N,"line_end":M} — вырезает кусок сценария целиком.

## Правила и типовые проблемы
Сначала спроси vanessa_kb (mode dense, вопрос своими словами): проведение документов, ожидание окон,
очистка тестовых данных, переключатели/гиперссылки, проверка отчётов — там готовые ответы с примерами.

## Workflow написания сценария
1. list_collections — что доступно и готово (vector_status=ready).
2. Составь план действий; на каждое действие — search по vanessa_steps (dense).
3. Сомнения — vanessa_kb; примеры — grep/get_segment по файловым коллекциям.
4. Проверь синтаксис: check_syntax. Выполняй пошагово execute_feature_step, целиком — run_scenario.
5. Состояние и результаты: get_VanessaAutomation_state, get_test_results.

## Частые ошибки
- Не подбирай шаги точной подстрокой — русская морфология ломает такой поиск; используй dense.
- Не выдумывай шаги: если лучший dense-скор < ~0.75 — переформулируй запрос или спроси vanessa_kb.
- Не меняй формулировку найденного шага (кроме первого слова И/Когда/Тогда и значений параметров).
