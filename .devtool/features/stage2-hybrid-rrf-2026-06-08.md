# Stage 2 — hybrid (RRF) + семантика score по режимам

Обязателен для доменов с точными идентификаторами (товары/клиенты): чистый dense проваливается на SKU/ИНН/артикуле.

## Acceptance
- [ ] `mode: dense | keyword | hybrid`
- [ ] dense: top-k по скаляру над нормализованными векторами
- [ ] keyword: полный скан (подстрока/regex) по коллекции — на 5–10к микросекунды, инвертированный индекс не нужен
- [ ] Слияние: **Reciprocal Rank Fusion (RRF)** двух ранжированных списков — без калибровки скоров между каналами
- [ ] **Документировать семантику `score`/`min_score` по режимам**: `dense` = косинус (порог абсолютный, осмысленный); `hybrid` = RRF-ранговый скор (величина без абсолютного смысла — порог по нему иной); `keyword` = присутствие/число матчей. `min_score` применим к `dense`; для `hybrid`/`keyword` — другая семантика или не применяется (чтобы не сравнивать RRF-скор с косинус-порогом)

Refs: §6.3, §5.3, §12.
